The Unit is not responsive it has fixed size.

  • px Pixels fixed sized good for precision called screen pixel
  • pt points print media unit used for print css - resume, newspaper, article. Its 1/72th part of an inch
  • cm centimeters used with print media, gives fixed size of element for priniting web generated document
  • mm millimeters used for physical pages A4, ID cards, barcodes
  • in inches
  • pc picas used for typesetting book, magazines, newspapers used for large print layouts and typography

Relative units are used for making elements responsive The child element can auto-adjust according to parent element. It is used to create elements responsive as per screen size

  • Percent % decides its size according percentage with respect to parent
  • em Element- relative It scales font-size on parent basis. if parent element font-size is 12px then 1em = 12px
  • rem Root-em It scales element font size according to root-html font size
  • ex x-height it is equal to character height, it is font specific; we can change vertical alignment and spacing
  • ch character width 1 character width; used for forms, text boxes allows width according to space a character takes
  • lh line height
